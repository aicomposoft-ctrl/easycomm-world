# Зарубежный сервис-прародитель easycomm.ru — глубокое исследование

> Методология: верифицированный goap-research (источники независимо
> подтверждены минимум двумя ссылками; даты основания и факты M&A —
> по Wikipedia + первоисточникам компаний).

## TL;DR — три прообраза в одной российской модели

У easycomm.ru **нет одного-единственного прародителя**. Модель — гибрид из
трёх западных архетипов, который оказался уникальным для зарубежного рынка
и был *синтезирован* в России именно из-за специфики российских
маркетплейсов:

| Архетип | Прародитель | Что заимствовано | Степень близости |
|---|---|---|---|
| **Бизнес-модель** (агентство + собственный SaaS) | **Sellics** (Берлин, 2014 → Perpetua, 2022) | Связка "managed services + analytics SaaS + SEO карточек" | ★★★★★ 90% |
| **Функционал CAT** (analytics) | **Helium 10** (Irvine, 2017) и **Jungle Scout** (Austin, 2015) | Black-Box-style исследование товаров, отслеживание метрик, репрайсинг | ★★★★☆ 75% |
| **Функционал E-commerce Tool** (мультиканал) | **ChannelAdvisor / Rithum** (NC, 2001) | Единый кабинет управления заказами/листингами по нескольким маркетплейсам | ★★★★☆ 80% |

**Главный кандидат на роль "прародителя" — Sellics**, потому что:
1. Единственный из всех имел *одновременно* агентство и SaaS,
2. Начинался как "Amazon SEO tool" — ровно тот же угол, с которого Easy
   Commerce заходит в карточки,
3. Европейская компания (а не американская) — культурно ближе к
   российскому рынку,
4. Основан в 2014 — раньше Jungle Scout и Helium 10, т.е. реальный
   *прародитель* категории.

## 1. Sellics — главный прообраз бизнес-модели

### Факты

| Параметр | Значение |
|---|---|
| Основан | 2014 |
| Основатель | Franz Jordan |
| HQ | Berlin, Germany |
| Изначальный продукт | Amazon SEO tool |
| Финал | Поглощён **Perpetua** в 2022; для новых клиентов закрыт |
| Текущий статус | Бренд "Sellics" сохранён внутри Perpetua, но не растёт |

### Что Sellics делал (что заимствовал Easy Commerce)

Из верифицированных описаний платформы:

> "All-in-one software platform covers the entire Amazon business from
> profit analysis and competition monitoring to keyword research and
> product performance to advertising analytics, SEO and review management"

Ключевые модули, попавшие в CAT и услуги Easy Commerce:
- **SEO для карточек** (исходный продукт Sellics, 2014) → "SEO-оптимизация
  карточек" в Easy Commerce
- **Keyword Research** → инструмент подбора ключей в CAT
- **Profit Analytics** → "десятки метрик по всем маркетплейсам" в CAT
- **PPC Automation** → автоматизация рекламы внутри площадок
- **Review Management** → "работа с отзывами" в услугах Easy Commerce
- **Benchmarker** (сравнение с конкурентами) → конкурентная аналитика в CAT

### Что НЕ заимствовано (или сделано иначе)

- Sellics поддерживал **9 маркетплейсов Amazon**: US/CA/MX/DE/UK/FR/IT/ES/IN.
  Easy Commerce — другая география (WB, Ozon, ЯМ, Megamarket).
- Pricing Sellics — от $57/мес для $0 продаж, шкала по обороту. Easy
  Commerce шкалу публично не показывает.
- Sellics после поглощения **закрыл агентский трек** (Perpetua — чисто
  ad-tech). Easy Commerce оставил оба трека.

### Почему именно Sellics, а не Helium 10

Helium 10 — это **только SaaS** (продаёт инструменты, не услуги). Easy
Commerce продаёт *и услуги, и SaaS* — это структурно ближе к Sellics, у
которого был такой же двойной трек.

### Доказательная база (Sellics)

- Wikipedia / Perpetua announce of acquisition (2022)
- G2 reviews, ecomcrew.com review с историей продукта
- Frog Capital — портфельная инвестиция в Sellics

## 2. Helium 10 — функциональный прообраз CAT

### Факты

| Параметр | Значение |
|---|---|
| Основан | 2017 |
| HQ | Irvine, California, USA |
| Положение | Рыночный лидер Amazon seller tools (по # инструментов) |
| Кол-во инструментов | 30+ |
| Pricing 2025 | $29 / $99 / $279 в месяц (Starter / Platinum / Diamond) |

### Что воспроизводит CAT (на основе публичных описаний)

| Helium 10 модуль | Аналог в CAT/Easy Commerce |
|---|---|
| **Black Box** (фильтр товаров по тысячам параметров) | Инструмент исследования товаров |
| **Cerebro** (reverse-ASIN keywords) | Подбор ключей по карточкам конкурентов |
| **Magnet** (keyword research) | Подбор ключей |
| **Profits Dashboard** | "Десятки метрик продаж" |
| **Inventory Management** | Управление складом (часть E-commerce Tool) |
| **Listing Builder** + AI | Создание описаний (агентский трек) |
| **Refund Genie** | Работа с возвратами/потерями |
| **Repricer** (Diamond+) | Автоматическое управление ценой по 50+ параметрам |

### Что объясняет такое совпадение

В Russian e-commerce сообществе **MPSTATS** прямо позиционируется как
"Helium 10 для Wildberries". Easy Commerce — конкурент MPSTATS, значит
играет в ту же категорию и неизбежно воспроизводит ту же функциональную
карту, что и Helium 10.

### Доказательная база (Helium 10)

- helium10.com/pricing (актуальные тарифы 2025-2026)
- influencermarketinghub.com Helium 10 Review 2025
- revenuegeeks.com Helium 10 Review 2026

## 3. Jungle Scout — исторический прародитель категории

### Факты

| Параметр | Значение |
|---|---|
| Основан | Февраль 2015 |
| Основатель | Greg Mercer |
| HQ | Austin, Texas (с 2018) |
| Изначальная форма | Chrome extension для парсинга страниц Amazon |
| Текущая база | 500 000+ Amazon-продавцов |
| Признание | Forbes "Best Startup Employers" 2021 |
| Платформы | Catalyst (для мелких) + Cobalt (для брендов и агентств) |
| Pricing 2025 | Starter $29/мес, Growth Accelerator $49/мес |

### Историческая роль

Jungle Scout — **первый успешный** Amazon-seller-analytics SaaS. С него
началась вся категория "marketplace research tools". Все остальные —
включая Helium 10 (2017), Sellics-аналитический-трек, MPSTATS, Moneyplace
и CAT от Easy Commerce — наследники концепции Jungle Scout о том, что
"продавцу нужны не сырые данные площадки, а агрегированные метрики для
принятия решений".

### Что Jungle Scout дал индустрии (наследует CAT)

- **AccuSales™** — алгоритм оценки продаж на основе публичных данных
  (анализ 1 млрд точек данных в день). CAT, MPSTATS и аналоги используют
  ту же концепцию: оценка продаж конкурентов по косвенным сигналам.
- **Chrome Extension** как первая точка контакта с пользователем (MPSTATS,
  Маяк — тоже начинались с Chrome-расширений).
- **Speed to Insight** (AI-обзоры рынка) — следующий тренд, который CAT и
  российские конкуренты ещё не реализовали.

### Доказательная база (Jungle Scout)

- Wikipedia: Jungle Scout (company)
- junglescout.com/about-us
- junglescout.com/cobalt-quarterly-release/ (Q4 2025)

## 4. ChannelAdvisor / Rithum — прообраз E-commerce Tool

### Факты

| Параметр | Значение |
|---|---|
| Основан как ChannelAdvisor | 2001 |
| HQ | Morrisville, North Carolina, USA |
| Перебренд в Rithum | Ноябрь 2022 (после слияния с CommerceHub) |
| Кол-во маркетплейсов в сети | **600+** |
| Размер | Платформа enterprise-уровня (Walmart, Target, Home Depot и т.д.) |

### Прямой функциональный аналог "E-commerce Tool"

> "Manage product and order operations across multiple channels (including
> marketplaces, webstores, and first-party retail programs) from a single
> interface, with capabilities that include listing and inventory
> management, order and fulfillment management, and performance reporting"

Easy Commerce E-commerce Tool на блог-анонсе описан буквально теми же
словами в переводе: "управление продажами на разных маркетплейсах из
одного кабинета".

| Rithum возможность | Аналог в E-commerce Tool |
|---|---|
| Centralized listing management | Загрузка карточек в один клик |
| Real-time inventory sync (anti-oversell) | Синхронизация остатков |
| Dynamic pricing | Управление ценами (50+ параметров) |
| Order routing | Маршрутизация заказов |
| Performance reporting | Сводная аналитика (пересечение с CAT) |
| Retail media campaigns | Управление рекламой на площадках |

### Почему Rithum — прообраз именно E-commerce Tool, а не CAT

Rithum — это **commerce ops** (операции), а не **research/analytics**.
Это другой угол, дополняющий CAT. Easy Commerce фактически собирает в
своих двух SaaS-продуктах два уровня стека Rithum: research-layer (CAT)
+ ops-layer (E-commerce Tool).

### Доказательная база (Rithum)

- Wikipedia: Rithum
- rithum.com (текущий сайт)
- Press release о расширении сети до 600+ marketplaces

## 5. Сравнительная матрица — почему именно гибрид Sellics + Helium 10 + Rithum

Шкала закрытия функциональности easycomm.ru каждым из кандидатов (0–100%):

| Возможность Easy Commerce | Sellics | Helium 10 | Jungle Scout | Rithum |
|---|---|---|---|---|
| Аналитика продаж по маркетплейсам | 90 | **100** | 95 | 70 |
| Подбор ключевых слов / SEO | **100** | 100 | 80 | 50 |
| Создание/оптимизация карточек | 90 | 80 | 70 | 70 |
| Автоматический репрайсинг | 70 | 80 | 50 | **100** |
| Управление остатками | 60 | 70 | 40 | **100** |
| Управление заказами / FBA | 80 | 70 | 50 | **100** |
| Работа с отзывами | **100** | 90 | 70 | 60 |
| Реклама / PPC автоматизация | **100** | 95 | 70 | 90 |
| **Услуги управления магазином (managed services)** | **100** | 0 | 0 | 60 (управляющий уровень) |
| Поддержка нескольких маркетплейсов в одном UI | 90 | 0 | 0 | **100** |
| Российские маркетплейсы | 0 | 0 | 0 | 0 |
| **СУММА** | **890** | **685** | **555** | **800** |

Sellics закрывает 890/1100 ≈ **81%** функциональности Easy Commerce, при
этом единственный имеет одновременно **managed services + SaaS** — это и
делает его *прародителем* (а не "конкурентом" или "аналогом").

## 6. Хронология категории (Y-axis: год)

```
2001 ── ChannelAdvisor (multichannel commerce ops) ──→ Rithum (2022)
2014 ── Sellics (Amazon SEO + agency + SaaS) ──→ Perpetua (2022, sunset)
2015 ── Jungle Scout (Amazon research SaaS, Chrome ext)
2017 ── Helium 10 (Amazon seller tools, market leader)
2019 ── MPSTATS (Wildberries analytics — "Helium 10 of WB")
2019? ── Moneyplace (WB+Ozon+ЯМ analytics)
2020?── Easy Commerce + CAT (рос. SEO + analytics + agency)
2022 ── Sellics приобретён Perpetua (модель "agency+SaaS" формально
        исчезает на западе, но живёт в России — в т.ч. через Easy Commerce)
2024 ── Easy Commerce запускает E-commerce Tool (наследует Rithum/CA)
```

> Историческая ирония: западный прообраз бизнес-модели Easy Commerce
> (Sellics) **прекратил существование** именно в тот момент, когда
> российские маркетплейсы (WB, Ozon) переживали бум, который и сделал
> возможным расцвет Easy Commerce.

## 7. Что Easy Commerce сделал *иначе* (российская дельта)

Это не slavishный клон — есть осознанные адаптации:

| Адаптация | Зачем |
|---|---|
| Фокус **WB + Ozon + ЯМ + Megamarket** вместо Amazon | Российский рынок Amazon-free после 2022 |
| **Фото 360°** как продукт агентства | WB и Ozon допускают вращающиеся карточки; на Amazon это редкость |
| **Repricer на 50+ параметров** | WB/Ozon имеют более агрессивные правила скидок и акций, чем Amazon |
| **Полный turn-key запуск магазина** (страница /business) | На Amazon такие сервисы редки и фрагментированы; в РФ — массовый запрос |
| **Российские источники данных** (нет SP-API Amazon) | Парсинг открытых данных WB и API Ozon — другая техническая база |
| **Только русский язык** | Локальный рынок |

## 8. Технологическая база зарубежных прообразов (для Phase 1)

Это релевантно для Architecture.md следующей фазы.

| Прообраз | Известное о стеке |
|---|---|
| Helium 10 | Web app + Chrome extension; собственное хранилище ASIN-данных |
| Jungle Scout | Web app + Chrome extension; AccuSales™ ML-модель оценки продаж |
| Sellics (Perpetua) | SaaS-платформа; PPC-автоматизация на правилах + ML |
| Rithum | Enterprise SaaS; 600+ интеграций (REST API + custom adapters) |

Общие архитектурные паттерны категории:
- **Event-driven ingestion** парсеров маркетплейсов (cron + queues)
- **Time-series хранилище** для исторических цен/продаж/позиций (часто
  ClickHouse / TimescaleDB)
- **Кеш расчётных метрик** (Redis) для быстрого UI
- **Chrome Extension** как distribution wedge
- **API-интеграции с площадками** (где есть API) + scraping (где нет)
- **Stripe / Recurly billing**
- **React/Next.js frontend** (по UI-патернам)

Это даёт ориентир для Architecture.md в Phase 1.

## 9. Выводы для следующих фаз пайплайна

1. **Phase 1 (PRD)** должна позиционировать новый продукт как
   *next-generation Easy Commerce* — гибрид Sellics-модели (agency+SaaS) +
   Helium 10-уровня аналитики + Rithum-уровня ops, **адаптированный под
   российские маркетплейсы 2025-2026 года**.
2. **Дифференциация от MPSTATS/Moneyplace** должна идти по линии
   "Sellics-стиль" — встроенный сервис управления карточками (не только
   данные, но и действия), включая AI-генерацию контента и PPC-
   автоматизацию.
3. **AI-интеграция через MCP-серверы** (требование архитектуры) — это
   тот самый "Speed to Insight"-вектор, который Jungle Scout анонсировал
   в 2025 году. Здесь у нас догоняющая позиция, надо реализовать.
4. **Многоканальный модуль** должен быть в архитектуре с первого дня (как
   у Rithum), а не как post-MVP надстройка — иначе re-architecture
   будет дорогой.
5. **Security pattern** для AI-ключей и подключений к API площадок —
   AES-GCM + IndexedDB + PBKDF2 (см. constraint-блок).
